# Изменения

## 2.0.1 — согласование интерфейса, без релиза

Один раздел альбомов, управление содержимым внутри альбома, тип «Галерея / Файлы» с фиксацией после сохранения. Вложенные альбомы, правая колонка параметров, fancy select родителя. Отдельные параметры каждого типа и общие WebP/качество/размеры/лимиты. Сохранение строк вместе с альбомом. Технические проверки отложены до самостоятельного просмотра пользователя.

## 2.0.0 — промежуточная неопубликованная сборка

Основа Joomla MVC, поддержка документов, миграция со старой схемы, WebAssetManager, переопределяемые макеты и подготовка GitHub update server. Предварительные категории и общий список файлов исключены из итоговой архитектуры.
