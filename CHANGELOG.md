# Изменения

## 2.1.1 — 28 октября 2026

Исправлено: страницы списка альбомов, альбома и дерева файлов прилегали заголовком вплотную к хлебным крошкам шаблона. Добавлены штатные отступы Bootstrap: сверху у страницы и под заголовком.

## 2.1.0 — 28 октября 2026

Вставка альбомов в материалы.

Плагин «Контент — Dharma Gallery»: код `{dharmagallery id=N}` в тексте материала выводит содержимое альбома теми же карточками, что страница компонента, с учётом доступа, публикации, языка и переопределений. Необязательные параметры `limit` (до 100) и `columns` (1, 2, 3, 4, 6). Несколько вставок на странице используют одно окно просмотра; индексатор Smart Search и тексты самих альбомов коды не обрабатывают.

Плагин «Кнопка редактора — Dharma Gallery»: пункт в меню «Контент» редактора открывает список альбомов с поиском и пагинацией, кнопка «Вставить» кладёт код в текст. Выбор передаёт штатный сценарий Joomla (postMessage), собственного JS нет.

Плагины входят в архив компонента и устанавливаются его скриптом; при первой установке включаются, при обновлении сохраняется выбор администратора, при удалении компонента удаляются.

Исправлено: проверка RTF отклоняла любые текстовые документы (`.txt`, `.csv`), у которых нет сигнатуры RTF; теперь сигнатура требуется только для `.rtf` и для `.doc`, определённых как RTF или текст.

Исправлено: при удалении компонента скрипт установки пытался выполнить миграции после удаления файлов и завершался ошибкой, оставляя в Joomla запись сервера обновлений.

## 2.0.5 — 27 октября 2026

Первый публичный выпуск переработанного компонента. Исправлен SQL-запрос проверки ссылок перед удалением оригиналов: имена полей экранируются, ссылки из текстов других альбомов и URL с кодированными именами также сохраняют общий файл. Подготовлена публичная лента обновлений Joomla и постоянный URL установочного ZIP.

Новый тип пункта меню «Дерево файлов»: файлы выбранного корня и вложенные альбомы на одной странице, компактные строки ссылок и отступы по уровням. Публикация и доступ проверяются для всей ветки; общие параметры файлов и переопределения альбомов сохраняются. Макет страницы, узлов и строк файлов можно переопределить в шаблоне.

Адреса альбомов формируются по алиасу без числового ID перед ним. Старые ссылки с ID продолжают разбираться; точный алиас имеет приоритет, включая алиасы с числом в начале.

Общие настройки распределены по вкладкам «Общие», «Галерея» и «Файлы». Добавлены глобальные параметры отображения с наследованием в альбомах и выбор просмотрщика Bootstrap Modal / WT Fancybox. WT подключается через локальный preset установленного плагина, со ссылкой на установку и возвратом к Bootstrap при его отсутствии. Исправлен перевод заголовка страницы настроек компонента.

Общий переключатель названий фотографий и переопределение в альбоме «Использовать общие / Да / Нет». Настройка учитывается в подписи карточки и заголовке окна просмотра.

Возврат из подальбома в соответствующий пункт меню списка; исключение дублирования корня списка в хлебных крошках. Интротекст над содержимым и полный текст под ним; старое описание сохранено без переноса данных. Новое поле добавляется идемпотентно установщиком.

Автоматическая обложка карточки: первое опубликованное и доступное посетителю фото самого альбома при отсутствии выбранной обложки. Для списка и подальбомов используется один запрос с учётом порядка изображений.

Сохранение кириллицы, пробелов и знака № в именах новых файлов; понятные суффиксы коллизий без перезаписи. Разрешённые расширения в общих настройках с проверкой новых загрузок и привязок файлов. Зафиксирован процесс: сайт → исходники → коммит/push, без промежуточных ZIP. Тесты по-прежнему отложены.

## 2.0.4 — сохранение загруженных документов

Результат загрузки сначала передаётся в API медиаполя Joomla. Устранён запуск повторной проверки документа до установки проверенного сервером пути: DOCX/XLSX не должны получать ложную ошибку поля. Серверная проверка файлов сохранена. Проверки интерфейса отложены по просьбе пользователя.

## 2.0.3 — карточки, загрузка и хранение

Карточки фотографий и документов на основе Joomla subform; загрузка сразу после выбора и перетаскивания. Папка загрузки и два параметра удаления оригиналов. Учёт собственных загрузок, сохранение общих файлов при удалении. Дерево альбомов до пагинации; опубликованные ветки в выборе родителя. Проверки отложены по просьбе пользователя.

## 2.0.2 — исправление отображения

Сохранённый тип альбома отображается штатным readonly-списком Joomla без Choices. Выбор типа при создании и защита от изменения после сохранения сохранены. Проверки отложены по просьбе пользователя.

## 2.0.1 — согласование интерфейса, без релиза

Один раздел альбомов, управление содержимым внутри альбома, тип «Галерея / Файлы» с фиксацией после сохранения. Вложенные альбомы, правая колонка параметров, fancy select родителя. Отдельные параметры каждого типа и общие WebP/качество/размеры/лимиты. Сохранение строк вместе с альбомом. Технические проверки отложены до самостоятельного просмотра пользователя.

## 2.0.0 — промежуточная неопубликованная сборка

Основа Joomla MVC, поддержка документов, миграция со старой схемы, WebAssetManager, переопределяемые макеты и подготовка GitHub update server. Предварительные категории и общий список файлов исключены из итоговой архитектуры.
