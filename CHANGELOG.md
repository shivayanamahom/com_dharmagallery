# Изменения

## Не выпущено — текущие правки на сайте

Сохранение кириллицы, пробелов и знака № в именах новых файлов; понятные суффиксы коллизий без перезаписи. Разрешённые расширения в общих настройках с проверкой новых загрузок и привязок файлов. Зафиксирован процесс: сайт → исходники → коммит/push, без промежуточных ZIP. Тесты по-прежнему отложены.

## 2.0.4 — сохранение загруженных документов

Результат загрузки сначала передаётся в API медиаполя Joomla. Устранён запуск повторной проверки документа до установки проверенного сервером пути: DOCX/XLSX не должны получать ложную ошибку поля. Серверная проверка файлов сохранена. Проверки интерфейса отложены по просьбе пользователя.

## 2.0.3 — карточки, загрузка и хранение

Карточки фотографий и документов на основе Joomla subform; загрузка сразу после выбора и перетаскивания. Папка загрузки и два параметра удаления оригиналов. Учёт собственных загрузок, сохранение общих файлов при удалении. Дерево альбомов до пагинации; опубликованные ветки в выборе родителя. Проверки отложены по просьбе пользователя.

## 2.0.2 — исправление отображения

Сохранённый тип альбома отображается штатным readonly-списком Joomla без Choices. Выбор типа при создании и защита от изменения после сохранения сохранены. Проверки отложены по просьбе пользователя.

## 2.0.1 — согласование интерфейса, без релиза

Один раздел альбомов, управление содержимым внутри альбома, тип «Галерея / Файлы» с фиксацией после сохранения. Вложенные альбомы, правая колонка параметров, fancy select родителя. Отдельные параметры каждого типа и общие WebP/качество/размеры/лимиты. Сохранение строк вместе с альбомом. Технические проверки отложены до самостоятельного просмотра пользователя.

## 2.0.0 — промежуточная неопубликованная сборка

Основа Joomla MVC, поддержка документов, миграция со старой схемы, WebAssetManager, переопределяемые макеты и подготовка GitHub update server. Предварительные категории и общий список файлов исключены из итоговой архитектуры.
