# Dharma Gallery

Общение и документация на русском. Исходники здесь; `../com_dharmagallery-1.1.0` — исходный дистрибутив, не изменять. Тестовая установка: `/Volumes/Work/Server/www/svg`, `http://svg.test/`.

## Принятая структура

- Только «Альбомы» и общие «Настройки». Нет отдельных категорий и общего раздела файлов.
- Альбомы вложенные. Тип `gallery` или `files` выбирается при создании и фиксируется после первого сохранения на сервере.
- Содержимое редактируется и загружается внутри формы альбома; подписи, порядок и удаления сохраняются вместе с альбомом.
- Справа компактная колонка параметров, родительский альбом выбирается штатным Joomla fancy select.
- Вкладка настроек альбома содержит только параметры его типа. WebP, качество, размеры копий и лимиты — в общих настройках компонента.

## Код и доставка

- Joomla MVC, формы, повторяемый subform, Bootstrap 5, WebAssetManager, LayoutHelper. Без inline CSS/JS и CDN.
- Таблицы `#__dharmagallery_albums` и историческая `#__dharmagallery_photos`. Изменения схемы только через версионные SQL-файлы; пользовательские файлы и переопределения не удалять.
- ACL, CSRF, проверка владельца каждой строки содержимого, расширений, MIME и путей обязательны.
- **Пользователь сначала проверяет понятность интерфейса сам. До его сигнала не запускать тесты, линтеры, CI-проверки и браузерные тестовые действия.** Можно собрать и установить пакет для его просмотра.
- Проверки для следующего этапа: `php tools/check.php`, `php tests/run.php`, реальная админка, загрузка, сохранение, фронтенд и обновление. Сейчас они отложены.
- Не создавать теги, релизы и непустую ленту `updates.xml` без прямого разрешения. Workflow только ручной, сейчас его не запускать.
