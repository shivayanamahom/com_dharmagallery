Компонент Joomla 6 для вложенных альбомов фотографий и документов: массовая загрузка, карточки, дерево файлов и переопределяемые макеты. Требования: PHP 8.3+, `fileinfo`, `zip`; для обработки изображений — `gd`, для WebP — `imagewebp`.

## Быстрая установка

В Joomla: **Система → Установка → Расширения → Установить по URL-адресу**:

```text
https://github.com/shivayanamahom/com_dharmagallery/releases/latest/download/com_dharmagallery.zip
```

Также можно скачать версионный ZIP в [Releases](https://github.com/shivayanamahom/com_dharmagallery/releases). Новые версии появляются в **Система → Обновление → Расширения**. Текущая версия — **2.0.5**; [история изменений](CHANGELOG.md).

> Разработчикам: перед правками прочитайте [AGENTS.md](AGENTS.md).

## Работа с альбомами

В меню компонента два пункта: **Альбомы** и **Настройки**. Всё содержимое управляется внутри альбома; отдельных категорий и общего списка файлов нет.

1. Создайте альбом, укажите название и выберите тип справа: **Галерея** или **Файлы**.
2. При необходимости выберите родительский альбом через штатный Joomla fancy select с поиском.
3. Сохраните альбом. Тип после первого сохранения не меняется.
4. На вкладке **Содержимое / Файлы** выберите несколько файлов с компьютера или перетащите их на панель: загрузка начинается сразу. Содержимое отображается карточками с превью фотографии или значком и форматом документа. Существующий файл можно добавить через медиаменеджер. Подписи, порядок, публикация и удаление строк находятся здесь же.
5. Нажмите **Сохранить**, чтобы применить изменения содержимого. Загрузка помещает оригинал в медиапапку; привязка к альбому сохраняется вместе с формой.

Галерея принимает изображения JPEG, PNG, WebP, GIF. Альбом «Файлы» принимает документы PDF, TXT, CSV, DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT/ODS/ODP и изображения в качестве скачиваемых файлов. Активные форматы, исполняемые файлы и произвольные архивы не принимаются. Проверяются расширение, MIME и структура офисного контейнера.

В общем списке альбомы показаны деревом: подальбомы идут под родителями с отступами. В качестве нового родителя можно выбрать только опубликованный альбом из опубликованной ветки. Во вкладке **Подальбомы** можно открыть дочерние альбомы и создать новый. Например, «Наши работы → Объект 1». Под одним родителем могут быть и галереи, и подборки документов; каждый дочерний альбом имеет свой закреплённый тип.

Имена новых файлов сохраняются на русском и с пробелами, например `Акт выполненных работ № 1.pdf`. Служебные символы нормализуются. Если имя занято, добавляется `(2)`, `(3)` и т. д.; существующий файл не перезаписывается. URL кодируются по сегментам пути, поэтому пробелы и кириллица работают в ссылках и превью.

## Настройки

Вкладка **Настройки** в альбоме зависит от его типа:

- Галерея: колонки, пропорции миниатюр, названия изображений и просмотр в окне. Параметры наследуются из общих настроек, а в альбоме можно задать своё значение. Существующее явное значение альбома сохраняется; чтобы применить общий параметр, выберите «Использовать общие настройки». Отключение названия убирает его под фото и в окне просмотра; альтернативный текст и отдельное описание сохраняются.
- Файлы: список или карточки, размер, формат и действие ссылки — открыть или скачать.

Общие **Настройки** компонента распределены по вкладкам:

- **Общие**: папка загрузки внутри images (по умолчанию images/dharmagallery), разрешённые расширения через запятую, удаление оригиналов при удалении элемента и при окончательном удалении альбома, лимиты загрузки и количество элементов на страницах.
- **Галерея**: колонки, пропорции, названия фотографий, просмотр в окне и выбор **Bootstrap Modal / WT Fancybox**, WebP, качество и размеры изображений и миниатюр.
- **Файлы**: список или карточки, отображение размера и расширения, открыть или скачать.

Для WT Fancybox нужен включённый [системный плагин WT Fancybox](https://web-tolk.ru/dev/joomla-plugins/wt-fancybox-js); ссылка есть в форме настроек. Компонент использует локальный WAM preset плагина и связывает только собственные ссылки. Если плагин недоступен, используется Bootstrap Modal. По умолчанию выбран Bootstrap; сохранённые настройки сайта автоматически не изменяются.

Оригиналы сохраняются; оптимизированные копии создаются в `images/dharmagallery-cache/`. Изменение оригинала или параметров создаёт новый адрес копии. Анимированный GIF открывается в оригинале.

Доступ и публикация относятся к альбому; отдельные элементы также можно снять с публикации. Удаление строки убирает запись после сохранения формы. По умолчанию оригинал остаётся на диске. При включённом удалении очищаются файлы, загруженные самим компонентом, и их копии; сохраняются файлы, на которые ссылаются другие альбомы, обложки, материалы, пользовательские поля и модули Joomla. Произвольные файлы, выбранные через медиаменеджер, не считаются собственностью компонента и не удаляются автоматически. Файлы в публичной папке `images/` остаются доступны по прямым URL; это не закрытое хранилище документов.

Интротекст выводится над содержимым альбома, полный текст — под ним. Существующее описание сохранено как полный текст; оба редактора находятся на вкладке «Подробности».

## Вывод и переопределения

Для документов добавлен тип пункта меню **Dharma Gallery → Дерево файлов** (`view=albums&layout=tree`). Укажите **Корневой альбом** либо **Все файловые альбомы**: на одной странице выводятся файлы корня, названия альбомов и вложенные подальбомы с отступами, без карточек и пагинации. Отдельные категории не создаются. Собственные изображения альбомов типа «Галерея» исключены; такие альбомы могут оставаться заголовками родительских веток документов. Учитываются публикация, доступ и язык всей ветки, а для файлов — публикация и доступ. Расширение, размер и действие ссылки наследуются из настроек соответствующего альбома. Интро и полный текст располагаются до и после содержимого своего альбома. Данные дерева и файлов загружаются общими запросами без запроса для каждого узла.

При перемещении альбома в корзину записи и файлы сохраняются для восстановления. Настройка удаления оригиналов альбома применяется при **окончательном удалении**, с проверкой остальных ссылок на файл.

В адресе альбома используется алиас без префикса ID: например, `/about/dokumentatsiya/primer-podkategorii-alboma`. Старые адреса вида `6-primer-podkategorii-alboma` сохраняют совместимость. Алиасы альбомов уникальны в компоненте.

Создайте пункт меню «Dharma Gallery: список альбомов» или «Dharma Gallery: альбом». На странице альбома показываются его подальбомы и собственное содержимое. Кнопка возврата использует пункт меню списка, если он представляет текущего родителя; иначе открывает родительский альбом. Корень списка не дублируется отдельным уровнем хлебных крошек. Если обложка не выбрана, карточка автоматически использует первое опубликованное изображение этого альбома по порядку сортировки, с учётом доступа посетителя. Выбранная вручную обложка имеет приоритет; поле в базе автоматически не заполняется. Используется Bootstrap 5 шаблона Joomla; CSS/JS подключаются через WAM без CDN.

- Страница: `templates/ВАШ_ШАБЛОН/html/com_dharmagallery/album/default.php`; список — `albums/default.php`.
- Карточки: `templates/ВАШ_ШАБЛОН/html/layouts/com_dharmagallery/album.php`, `image.php`, `file.php`, `items.php`, `lightbox.php`.
- Дерево файлов: страница `templates/ВАШ_ШАБЛОН/html/com_dharmagallery/albums/tree.php`, узел и строка файла — `templates/ВАШ_ШАБЛОН/html/layouts/com_dharmagallery/tree-node.php` и `tree-file.php`.
- Исходники карточек в `site/layouts/`, данные в `$displayData` (`item`, `params`).
- Альтернативные макеты страниц поддерживаются штатным механизмом Joomla `layout`.
- Старые переопределения Spargo нужно адаптировать к новой структуре данных; компонент их не изменяет.

Список разрешённых форматов ограничивает новые загрузки и добавление/замену пути через медиаменеджер. Галерея использует только разрешённые изображения. Уже сохранённые вложения не блокируются при сокращении списка; MIME и содержимое продолжают проверяться. Разрешаются только форматы из поддерживаемой компонентом карты типов.

## Сборка и обновления

Исходники компонента хранятся в этом репозитории. Установочные архивы публикуются в GitHub Releases; исходный ZIP GitHub не является установочным пакетом Joomla.

```sh
php tools/check.php
php tests/run.php
php tools/build.php
```

Сборка создаёт `dist/com_dharmagallery-2.0.5.zip`, копию `com_dharmagallery.zip` для постоянной ссылки и контрольные суммы `SHA256SUMS.txt`. Проверки не создают теги и релизы; workflow запускается вручную.

Сервер обновлений: `https://raw.githubusercontent.com/shivayanamahom/com_dharmagallery/main/updates.xml`. Лента содержит версию, адрес установочного ZIP, SHA-256 и требования Joomla/PHP. Установка и обновление используют штатный менеджер Joomla.

Миграции с 1.1.0 сохраняют ID, вложенность и пути фотографий. Данные промежуточной сборки с файлами без альбома сохраняются в неопубликованном альбоме «Файлы из предыдущей сборки». Исторический `catid` в таблице оставлен неиспользуемым для сохранности старой схемы. Таблица `#__dharmagallery_uploads` хранит сведения о загруженных самим компонентом оригиналах, включая ещё не привязанные к сохранённой форме.

## Проверка

Перед выпуском выполняются проверки PHP/XML/языковых файлов и ленты обновлений, тесты типов и путей файлов, сборка и проверка ZIP. На тестовом сайте проверяются сохранение содержимого, закреплённый тип альбома, публикация вложенной структуры, ссылки по алиасам, защита чужих строк и удаление оригиналов/копий с сохранением общих файлов. После установки проверяется версия установленного компонента и регистрация сервера обновлений.

Проверки не заменяют проверку переопределений и настроек конкретного сайта после обновления.
