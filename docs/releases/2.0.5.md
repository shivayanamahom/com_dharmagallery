Первый публичный выпуск переработанного Dharma Gallery — компонента вложенных альбомов фотографий и документов для Joomla 6.

## Возможности

- Альбомы и подальбомы с типом «Галерея» или «Файлы»; тип закрепляется после первого сохранения.
- Управление содержимым внутри альбома: карточки, массовая загрузка, перетаскивание, подписи, порядок и публикация.
- Штатные формы Joomla, медиаменеджер, права доступа, правая колонка параметров и поиск родительского альбома.
- Сетка фотографий, карточки/список файлов и новый тип меню «Дерево файлов» с вложенными заголовками и ссылками на одной странице.
- Bootstrap Modal или WT Fancybox через установленный системный плагин; локальные ресурсы без CDN.
- Общие настройки и переопределение в альбомах: колонки, пропорции, названия фотографий, размер и формат файла, открыть или скачать.
- Интротекст над содержимым и полный текст под ним; автоматическая обложка из первого доступного фото, если обложка не задана.
- Кириллица и пробелы в именах файлов, разрешённые расширения, проверка MIME и содержимого документов, исключение перезаписи файлов.
- Оригиналы сохраняются; WebP и миниатюры формируются как отдельные копии. Удаление оригиналов настраивается отдельно и сохраняет файлы, используемые в другом контенте.
- Адреса альбомов без числового ID; совместимость прежних ссылок. Переопределяемые страницы, карточки, дерево и просмотрщик.
- Обновление через стандартный менеджер Joomla и публичную ленту GitHub.

## Исправлено перед выпуском

Исправлена проверка ссылок перед удалением файлов: поле `fulltext` экранируется в SQL. Очистка корзины альбомов и удаление файлов из сохранённого альбома больше не оставляют оригиналы из-за ошибки этого запроса. Ссылки из текстов других альбомов и кодированных URL также учитываются.

## Установка / обновление по URL

В Joomla: **Система → Установка → Расширения → Установить по URL-адресу**:

```text
https://github.com/shivayanamahom/com_dharmagallery/releases/download/v2.0.5/com_dharmagallery-2.0.5.zip
```

Постоянная ссылка на последнюю версию:

```text
https://github.com/shivayanamahom/com_dharmagallery/releases/latest/download/com_dharmagallery.zip
```

Дальнейшие версии появляются в **Система → Обновление → Расширения**. Руководство: [README](https://github.com/shivayanamahom/com_dharmagallery#readme), [история изменений](https://github.com/shivayanamahom/com_dharmagallery/blob/main/CHANGELOG.md).

**Требования:** Joomla 6, PHP 8.3+, `fileinfo`, `zip`; `gd` для обработки изображений. WT Fancybox — по желанию. Для крупных изображений нужны достаточные лимиты памяти и загрузки PHP.

При обновлении с 1.1.0 сохраняются альбомы, их ID, вложенность и пути файлов. Старые переопределения шаблона необходимо адаптировать к новой структуре компонента. Перед обновлением рабочего сайта сделайте резервную копию.

**Проверено:** 47 PHP-файлов без ошибок синтаксиса, XML и языковые файлы, 22 теста проверки файлов и 10 проверок на Joomla (сохранение, закреплённый тип, вложенность/публикация, маршруты и защита/удаление файлов). В браузере проверены дерево документов, WT Fancybox и переходы по алиасам/возврат. Релизный ZIP установлен поверх рабочей сборки на тестовом сайте.
